GitHub公開用 軽量版（太秦安井二条裏町 LP）
1. ZIPを展開してください。
2. index.html、style.css、script.js、README.txt、assetsフォルダの中身を一緒にリポジトリにアップロードしてください。
3. ZIPそのものをGitHubの「Add file > Upload files」でアップロードするのではなく、展開後のファイルを登録してください。
4. GitHub Pagesを利用する場合は Settings > Pages > Deploy from a branch > main / (root) を指定。
5. ルートに index.html を置く必要があります。
※ 画像の建築デザイン・構図は変更せず、WebP圧縮のみ実施。
